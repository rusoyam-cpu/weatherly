# Weatherly 🌤️

Modern, lightning-fast, and sleek weather application built with Vanilla JavaScript and Open-Meteo API. No API key required!

## 🚀 Features
- **Real-time Search:** Search weather conditions for any city worldwide instantly.
- **Modern UI/UX:** Sleek glassmorphism design with dynamic glowing background effects.
- **Detailed Metrics:** Temperature, humidity, wind speed, feels-like temperature, and atmospheric pressure.
- **Zero Config:** Works completely out of the box without needing any API keys.

## 🛠️ Built With
- **HTML5 & CSS3:** Flexbox, Glassmorphism design, custom animations.
- **JavaScript (ES6+):** Async/Await, Fetch API for real-time data handling.
- **API:** [Open-Meteo API](https://open-meteo.com/) (Free Geocoding & Weather Forecast)
